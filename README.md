# OSINT Tools: a link-checked directory

A hand-maintained list of 210 open-source intelligence (OSINT) tools, sorted by task and labelled by price. Every link is checked by hand.

**Searchable version, with "start with what you have" filters:** https://osintresourcecenter.com

Last reviewed: 2026-11-13

## How this list is maintained

- **Listed when** the tool works, does one clear job, and is legal to use as described.
- **Removed when** the link is dead for 14 days, a paywall appears without warning, or the tool behaves deceptively.
- **Labelled** Free, Freemium or Paid.
- Fake ID, SSN and credit card generators are deliberately left out.

Found a dead link or a wrong label? [Open an issue](../../issues) or email onionbag2@proton.me.

The same data is in [`tools.json`](tools.json) if you want to build on it.
